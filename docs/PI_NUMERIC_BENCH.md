# Float / fixed-point PI на JK42BLS01

Проверено на STM32G431, Release `-Os`, около 20,8 В, без нагрузки на валу.
Выбор арифметики выполняется при сборке через `PI_NUMERIC_PROFILE=float|fixed`.

## Область реализации

Профиль переключает **общий регулятор скорости и токовый PI six-step**.
`PiController<Types, SampleRateHz>` хранит и вычисляет состояния в выбранных типах.
`PiFloatInterface` выполняет явные преобразования на границе существующих
измерений, настроек и выходов.

ADC, Hall PLL, FOC (включая его собственные d/q-регуляторы), PWM-интерфейс
и телеметрия пока используют float. Это этап проверки fixed-point ядер
на текущем оборудовании; сквозная параметризация продолжается по
[основному плану](NUMERIC_PROFILES_PLAN.md).

Частоты — целые compile-time параметры: 100 Гц для скорости, 20 кГц для тока.
Для скорости используются Q24-коэффициенты, для тока — Q16; дискретные
коэффициенты обоих PI имеют 28 дробных битов. Аккумуляторы — int64 с 32
дробными битами. Форматы входов: скорость Q16, ток Q20; выход тока — duty Q30.

Преобразование float → fixed разбирает IEEE-754 битовыми операциями, округляет
к ближайшему с половинами от нуля и сообщает переполнение. Неконечные или
выходящие за диапазоны настройки отклоняются без изменения предыдущей
конфигурации. Проверяется также диапазон дискретных коэффициентов.

## Сборка

```bash
cmake -S STM32G431 -B STM32G431/build-bench-float \
  -DCMAKE_BUILD_TYPE=Release -DPI_NUMERIC_PROFILE=float \
  -DENABLE_THROTTLE_BRAKE_CONTROL=OFF -DENABLE_BENCH_PROFILING=ON
cmake --build STM32G431/build-bench-float -j8

cmake -S STM32G431 -B STM32G431/build-bench-fixed \
  -DCMAKE_BUILD_TYPE=Release -DPI_NUMERIC_PROFILE=fixed \
  -DENABLE_THROTTLE_BRAKE_CONTROL=OFF -DENABLE_BENCH_PROFILING=ON
cmake --build STM32G431/build-bench-fixed -j8
```

`AT+VER?` отвечает `1.0.0-pi-float` или `1.0.0-pi-fixed`.
Для экспериментальной ветки используется её `utility/monitor.py`: PI-команды
содержат два коэффициента.

## Проверки на host

- `tests/test_numeric/run.sh`: 1092 проверки с UBSan, в том числе IEEE-754
  границы, смешанные форматы, округление, насыщение и накопление малых ошибок.
  Fixed PI и преобразование входа компилируются для Cortex-M0 без float helpers.
- `tests/test_pi_interface/run.sh`: одинаковые входные последовательности
  подаются в float/fixed PI, включая квантование ADC и насыщение.
- `tests/test_control/run.sh float` и `... fixed`: команды, частоты,
  ограничитель ускорения, смена настроек и отказ при переполнении формата.
- `tests/test_hall_handoff/run.sh fixed`: повторный запуск после OPEN-LOOP
  и сохранение реальной оценки скорости при вращении по инерции.

На одинаковых входах максимальное различие выходов:

| Контур | Максимальная разность |
|---|---:|
| Ток → duty | 0,00017705 duty |
| Скорость → ток | 2,96 мкА |
| Скорость → duty | 0,00009392 duty |

Разность duty меньше одного отсчёта таймера PWM (примерно 0,000235),
разность тока существенно меньше разрешения ADC.

## Проверки на моторе

Использованы настройки из [JK42BLS01_TUNING.md](JK42BLS01_TUNING.md):
ток 0,15/200, скорость в токовом режиме 0,01/0,05, PLL 100/5000,
ускорение 20 об/с².

### Ступени тока 0,15 ↔ 0,40 А

| Показатель | float PI | fixed PI |
|---|---:|---:|
| Медиана установления вверх | 1,70 мс | 2,05 мс |
| Медиана установления вниз | 1,85 мс | 1,55 мс |
| RMS ошибки на записи после первых 5 мс | 23,89 мА | 26,02 мА |
| 95-й процентиль абсолютной ошибки | 40 мА | 49 мА |

По 10 переходов и 11 полных OSC-буферов на профиль. Измерение установления:
среднее пяти отсчётов входит в ±25 мА и удерживается 1 мс. Фазы механического
движения и коммутации между отдельными прогонами различаются.
На неподвижном поле fixed PI также удерживает 0,15 и 0,40 А.

### Скорость, токовый режим, FORWARD

| Задание, об/с | float: среднее ± σ | fixed: среднее ± σ |
|---:|---:|---:|
| 2 | 2,032 ± 0,495 | 1,981 ± 0,487 |
| 5 | 5,021 ± 0,161 | 5,021 ± 0,185 |
| 10 | 10,030 ± 0,172 | 9,991 ± 0,154 |
| 20 | 19,997 ± 0,166 | 19,985 ± 0,123 |

Fixed PI дополнительно проверен в REVERSE: 5,015 / 10,012 / 20,007 об/с
для заданий 5 / 10 / 20. В режиме управления напряжением в REVERSE получены
1,994 / 9,974 / 19,968 об/с для заданий 2 / 10 / 20. Проверен переход к нулю.
Ошибок Hall в этих прогонах нет; существующие малоскоростные пульсации
токового режима наблюдаются с обеими арифметиками.

Средняя телеметрия тока включает отсчёты после коммутации, которые PI временно
не использует. В захватах на 20 об/с средняя ошибка всех OSC-отсчётов была
−2,75 мА для float и +6,50 мА для fixed. Если исключить 8 отсчётов после
коммутаций, восстановленных по углу OSC, получаются −1,12 и −1,05 мА.
Поэтому отличие общей телеметрии здесь не равно смещению вычислений PI.

### Время и память

По DWT, 20 000 вызовов на профиль, с включённым OSC, при 20 об/с:

| Показатель | float PI | fixed PI |
|---|---:|---:|
| Среднее время callback PWM | 17,55 мкс | 22,08 мкс |
| Максимальное наблюдавшееся время | 23,29 мкс | 28,69 мкс |
| Превышения 50 мкс | 0 | 0 |
| ELF text | 67 908 байт | 70 780 байт |
| ELF data | 520 байт | 520 байт |
| ELF bss | 16 112 байт | 16 128 байт |

Замер включает контроллер и захват OSC внутри callback; вход/выход аппаратного
IRQ и обвязка HAL в него не включены. Это наблюдавшийся максимум данных
прогонов. На Cortex-M4 с FPU fixed PI медленнее примерно на 4,5 мкс в среднем.
Статические stack-usage отчёты: обвязка callback 96 байт, PWM-метод контроллера
136 байт; fixed PI тока — отдельный кадр 96 байт, скорости — 104 байта.

## Найденная ошибка переключения режимов

Первое сравнение выявило дефект, независимый от арифметики: после OPEN-LOOP
PLL мог сохранить виртуальный сектор, а физический Hall без нового фронта
не перечитывался. Мотор стоял под током. Добавлена синхронизация с реальным
датчиком при выходе из OPEN-LOOP и проверка положения при выходе из NEUTRAL.
Реальное отслеживание вращения по инерции сохраняется. Исправление вынесено
в `main` вместе с регрессионным тестом на 18 проверок.
